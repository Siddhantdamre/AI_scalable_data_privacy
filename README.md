# AI_scalable_data_privacy

Privacy-preserving AI research sandbox exploring scalable federated, distributed, and adaptive data-protection methods.

## What It Does

- Collects experimental scripts for privacy-aware AI workflows.
- Explores scalable privacy and distributed learning ideas.
- Serves as a lightweight research sandbox for comparing approaches.

## Tech

Python, data privacy, federated learning concepts, distributed AI experiments.

## Repository Map

- `BMDP.py`, `IAAD.py`, `SFL.py` - method-specific experiments.
- `combinedcode.py` - combined workflow sketch.

## Status

Research sandbox and prototype code.
